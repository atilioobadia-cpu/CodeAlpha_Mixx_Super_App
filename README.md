# Mixx Super App - Fintech UI

**Style:** Mixx by Yas / M-Pesa inspired fintech super app.

## Features
- Navy header with greeting, hamburger, bell, search
- Hero balance card (navy, yellow amount, send/refresh/hide actions)
- Carousel dots
- Service grid (4 columns, 3 rows) with outline icons
- Promo banner with yellow shape + photo
- Bottom nav with floating yellow scan button

## Tech
HTML, CSS, JavaScript, Lucide icons, Poppins font.
